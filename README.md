# R&R Gardening Services - Professional Gardening & Guttering Website

A professional website for award-winning residential gardening and guttering services across the West Midlands.

## Features

- **Full-screen hero section** with stunning garden imagery
- **Responsive design** that works on all devices
- **Professional services showcase** including:
  - Grass cutting, treatment, and mowing
  - Hedge cutting and maintenance
  - Weed control and invasive weed management
  - Turf laying
  - Power washing
  - Garden clearance and disposal
  - Guttering services (cleaning, repair, installation)
- **Award-winning credentials** prominently displayed
- **Carbon neutral status** highlighting environmental responsibility
- **West Midlands coverage** with local expertise
- **Technology and innovation** leadership messaging
- **Contact form** for quote requests

## Getting Started

Simply open `index.html` in your web browser to view the website locally.

## Deployment

### GitHub Pages
This site can be deployed to GitHub Pages on every push to the main branch.

### Local Development
```bash
# Clone the repository
git clone https://github.com/yourusername/rr-gardening-services.git

# Navigate to the directory
cd rr-gardening-services

# Open in browser
open index.html

# Or use Python server
python3 -m http.server 8000
```
